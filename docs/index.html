🤖 DeepSeek Harness 📱 Android · Termux ⚡ One-click deploy

Put DeepSeek Harness
in your pocket

A native Android control app: Termux setup wizard, model-matched downloads, one-click deploy, live logs, built-in browser and storage manager. Tap-only — no command line.

⬇ Download APK GitHub Repo

🚀 Three steps to run

Transfer the APK to your phone once; everything else happens in the app.

1Download & install Termux in-app (model-matched)
→
2One-click deploy DeepSeek Harness (fastest mirror auto-picked)
→
3Open Harness and enter your API Key

✨ Features

🧭

Termux wizard

Detects model & ABI, downloads the matching APK in-app and launches the system installer.

🚀

One-click deploy

Auto speed-tests mirrors → installs toolchain → compiles native modules → starts the service, with live logs.

📟

Triple-channel logs

Heartbeat push + early progress server + control daemon — logs visible from second zero.

🌐

Built-in browser

Use Harness in a WebView; open externally in any installed browser (Via by default).

🎛

Service control

Start / stop / restart / status / logs — tap-only.

🔛

Termux on/off

Start or shut down Termux right from the app.

📁

Storage manager

Browse/edit sessions, attachments, skills, MCP config; one unified data root for shared storage.

🔋

Anti-freeze guide

Model-aware battery-optimization steps so the service never gets frozen.

🎨

Apple design

iOS palette, spring animations, haptics — down to button press feel.

📁 Storage locations

One data root ~/.dsh (migratable to /sdcard/dsh-data).

DataPath
Credentials~/.dsh/.credentials.yaml
Settings~/.dsh/settings.yaml
Sessions~/.dsh/sessions/<project>/<session>/session.jsonl
Attachments~/.dsh/attachments/v1/objects/<sha256…>
Skills~/.dsh/skills · ~/.agents/skills · project-level .dsh/skills
MCP config~/.dsh/profiles/ profile patches (cordis.patch.yml)
