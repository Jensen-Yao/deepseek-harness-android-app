✨ 特性

🧭

Termux 引导

识别机型与架构，App 内下载匹配安装包并调起系统安装器。

🚀

一键部署

自动测速选源 → 装工具链 → 编译原生模块 → 启动服务，全程实时日志。

📟

三通道日志

脚本心跳上报 + 早期进度服务 + 控制守护进程，日志从第 0 秒可见。

🌐

内置浏览器

WebView 直接使用 Harness；外部打开可选任意已装浏览器（默认 Via）。

🎛

服务控制

启动/停止/重启/状态/日志，点按完成，不碰命令行。

📁

存储管理

浏览/编辑会话、附件、技能、MCP 配置；统一数据根一键迁移共享存储。

🔋

防冻结引导

按机型提示电池优化设置，服务不再被系统冻结。

🎨

Apple 设计

iOS 色板、弹簧动画、触觉反馈——细节到按钮的按下手感。

📁 存储位置一览

数据根 ~/.dsh（可整体迁移到 /sdcard/dsh-data）。

数据路径
凭证~/.dsh/.credentials.yaml
设置~/.dsh/settings.yaml
会话~/.dsh/sessions/<项目>/<会话>/session.jsonl
附件~/.dsh/attachments/v1/objects/<sha256…>
技能~/.dsh/skills · ~/.agents/skills · 项目级 .dsh/skills
MCP 配置~/.dsh/profiles/ 配置档案（cordis.patch.yml）
